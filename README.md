# 💙 HappyMoney

> Aplicativo desktop para controle financeiro, desenvolvido com **Electron, JavaScript, HTML e CSS**.

## 🚀 Recursos

| 💰 Finanças           | 🖥️ Interface           | ⚙️ Sistema              |
| --------------------- | ----------------------- | ----------------------- |
| Controle de despesas  | Dashboard               | 100% Offline            |
| Planilhas de economia | Cards financeiros       | Armazenamento local     |
| Cadastro de gastos    | Modais interativos      | Arquivos `.sk`          |
| Despesas do mês       | Splash Screen           | Windows                 |
| Barras de progresso   | Configurações           | Electron                |
| Controle de valores   | Notificações            | Testes automatizados    |
|                       | Tela Sobre              | Versão portátil         |
|                       | Interface azul e branca | Validação de interações |

## 📦 Distribuição

**Windows • Instalável • Portátil • 100% Offline**

## 🛠️ Tecnologias

`Electron` `JavaScript` `HTML` `CSS` `Node.js`
